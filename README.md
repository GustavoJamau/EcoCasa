# EcoCasa 🌍♻️

> Site responsivo para conscientização ambiental (ODS 13). Ensina a aplicar a Regra dos 3 Rs e a desenvolver projetos Maker sustentáveis com Arduino.

O **EcoCasa** é um projeto de extensão universitária do curso de Ciência da Computação, focado em unir tecnologia, educação ambiental e a Cultura Maker. O objetivo principal é democratizar o acesso à informação sobre ações climáticas que podem ser aplicadas no dia a dia doméstico, incentivando a redução do desperdício e a criação de automações sustentáveis com eletrônica básica.

---

## ✨ Funcionalidades

- **Design Responsivo:** Interface adaptável para computadores, tablets e smartphones.
- **Modo Escuro (Dark Mode):** Alternância de tema integrada com `localStorage` para salvar a preferência do usuário.
- **Guia dos 3 Rs:** Orientações práticas sobre como Reduzir, Reutilizar e Reciclar no cotidiano.
- **Dicas de Economia:** Estratégias simples para economizar água e energia elétrica em casa.
- **Projetos com Sucata:** Tutoriais visuais (via YouTube) para reaproveitamento de garrafas PET e rolhas.
- **Mural Maker (Arduino):** Projetos de eletrônica voltados para o meio ambiente, contendo o código em C++ e botões para simulação direta no Tinkercad:
  - 🗑️ *Lixeira Automática com Sensor Ultrassônico*
  - 🌡️ *Termômetro de LED Inteligente*

---

## 🛠️ Tecnologias Utilizadas

- **Front-end:** HTML5, CSS3 e JavaScript (Vanilla).
- **Hardware/Simulação:** Arduino (C++) e plataforma Autodesk Tinkercad.

## 🚀 Como acessar e executar o projeto

Você pode interagir com o projeto de duas formas: acessando-o diretamente pelo navegador ou baixando os arquivos para o seu computador.

### 🌐 Acesso Online (Recomendado)
O projeto está hospedado no GitHub Pages para acesso rápido e fácil, sem necessidade de downloads.
👉 **[Acessar o EcoCasa Online](https://SEU-USUARIO.github.io/ecocasa)** *(Lembre-se de substituir este link pelo seu link real do GitHub Pages)*

### 💻 Execução Local (Download)
O projeto foi construído em formato *Single-Page* (página única) para máxima leveza. Não há necessidade de instalar *frameworks* ou dependências.

1. Faça o clone do repositório ou baixe o arquivo `.zip` (no botão verde "Code" no topo da página):
   `git clone https://github.com/SEU-USUARIO/ecocasa.git`

2. Extraia os arquivos (caso tenha baixado o `.zip`) e navegue até a pasta do projeto:
   `cd ecocasa`

3. Abra o arquivo `index.html` diretamente no seu navegador de preferência.

*Opcional:* Se você usa o VS Code, pode abrir o projeto com a extensão **Live Server**.
